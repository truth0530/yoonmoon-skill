# 마무리 점검

## grep 패턴 (사용자에게 보이는 파일만, 코드 주석 제외)
```
~않습니다      : 「않습니다」
세다 계열      : 「센다|셉니다|세지 않|세는|세어」
어색한 자동사  : 「숨습니다」
조사 오류      : 「[가-힣]+(를|는)\b」 중 받침 있는 말 뒤
이력 문구      : 「예전에는|이전 버전|더 이상|바뀌었|(구)」
단위 없는 숫자 : 「\d+/\d+(?!\s*[가-힣])」
```

## 체크리스트
- [ ] 의미가 바뀐 문장이 없는가(사실↔지시가 뒤바뀌지 않았는가)
- [ ] 사실 문장은 수동·결과형, 지시 문장은 명령형인가
- [ ] 설명서·용어집·시험 기대의 인용이 같은 문구로 맞춰졌는가
- [ ] 라벨(화면 이름)은 사용자가 정했는가
- [ ] 줄바꿈 규칙이 팝업·튜토리얼에 일관되게 적용되었는가
- [ ] 고치지 않고 남긴 문장과 이유를 보고했는가
- [ ] 관련 시험을 돌려 통과를 확인했는가
