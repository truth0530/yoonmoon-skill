# 한국어 윤문 규칙 (요약본)

한국어 화면 문구·안내문·팝업·설명서를 고칠 때 이 규칙을 따른다. 의미는 바꾸지 않는다. 뜻이 불분명하면 고치지 말고 질문으로 남긴다.

## 핵심
문장이 **프로그램이 그렇게 동작한다는 사실**인지, **사용자에게 그렇게 하라는 지시**인지 한눈에 드러나게 쓴다.
- 사실(동작): 「~됩니다」「~에서 빠집니다」「집계됩니다」「없습니다」
- 지시(사용자 행동): 「~하세요」「~하지 마세요」「~하면 안 됩니다」

## 규칙
1. 「~않습니다」는 사실인지 금지인지 모호하므로 피한다. 금지는 「~하면 안 됩니다」「~하지 마세요」, 사실은 「~되지 않습니다」「~에서 빠집니다」.
2. 「센다·셉니다·세지 않는다·세는」 같은 「세다」 계열을 쓰지 않는다. 「집계한다」「카운트한다」「측정한다」를 쓴다. 사실은 「집계됩니다」「집계에서 빠집니다」, 지시는 「집계에 넣으세요」「집계하지 마세요」. 꼭 써야 하면 지시형만 쓴다(「세지 마세요」「세면 안 됩니다」「세어 주세요」). 화면 라벨 이름은 후보를 제안하고 사용자가 정한다.
3. 어색한 자동사·피동을 고친다: 「숨습니다」→「숨겨집니다」, 「보여집니다」→「보입니다」.
4. 번역투와 군더더기를 걷어낸다: 「~에 의해 ~됩니다」→「~가 ~합니다」, 「~하는 것이 가능합니다」→「~할 수 있습니다」, 「~를 가지고 있습니다」→「~가 있습니다」. 단위 없는 숫자(「39/39칸」)는 「39칸 중 39칸」. 임의로 만든 용어를 쓰지 않는다.
5. 조사 오류(「배정를」→「배정을」)를 고친다. 변수가 들어가는 문장은 조사가 필요 없게 다시 쓴다.
6. 현재 상태만 쓴다. 「예전에는」「이전 버전에서는」「더 이상」「바뀌었습니다」 같은 이력 문구를 넣지 않는다.
7. 팝업·튜토리얼·긴 안내는 한 문장 한 줄, 문단 사이 빈 줄 하나, 절차는 번호(`1. `), 병렬 항목은 글머리(`· `)로 쓰고 둘째 줄부터 내어쓴다. 3~6줄을 권장한다.
8. 합쇼체(「~합니다」)로 통일하고, 같은 개념은 한 이름으로 쓴다. 용어집을 한 곳에 두고 화면이 그것을 가져다 쓴다.

## 작업 순서
1. 전수 조사: 문제 표현을 표(파일:줄, 현재 문구, 유형, 사실/지시)로 만든다. 코드 주석은 건드리지 않는다.
2. 분류: 사실 / 지시 / 라벨(화면에 보이는 짧은 이름)로 나눈다.
3. 교체: 유형별로 한 번에 하나씩 고친다.
4. 동기화: 문구를 인용하거나 글자로 비교하는 곳(설명서, 시험 기대, 용어집)을 같은 문구로 맞춘다.
5. 검수: 남은 패턴을 검색하고(「않습니다」「센다|셉니다|세지 않|세는」「숨습니다」「예전에는」), 전/후 표와 질문 목록을 보고한다.
